\section*{Introducción}
El presente trabajo tiene como objetivo evaluar la eficacia de modelos como KNN y árboles de decisión para identificar los caracteres del
dataset EnglishTypeAlphabet.
\newline
\newline
Una primera dificultad aparece al enfrentarse con el procesamiento de imágenes.
\newline
La detección de caracteres presenta como desafíos a resolver la gran cantidad de variantes para cada letra y las similitudes entre algunas de ellas.
\newline
\newline
Se realizó un análisis exploratorio a los fines de familiarizarse con la tarea e identificar los mejores modelos con sus correspondientes
hiperparámetros.
\newpage
\section*{Análisis Exploratorio}
El dataset está conformado por 26416 filas y 785 atributos. El atributo 'label' (que nos indica la letra) y 784 atributos (cada uno por pixel)
que representan una matriz de 28x28. Cada pixel es representado por un atributo toma un valor de 0 a 255 (escala de grises).
\newline
\newline
Cabe destacar que para cada letra hay 1016 variantes, por lo que se trata de un dataset perfectamente balanceado.
\newline

\section*{Experimentos realizados}
\subsection*{Clasificación Binaria}
Este experimento busca clasificar una imágen en las categorías O y L. Para esto se separó un subconjunto del dataset original que contiene las
imágenes correspondientes a la letra O y L. Se verifica que ambas clases se encuentran balanceadas (ya que cada letra
consta de 1016 variantes/imágenes). Posteriormente se separa el subconjunto en train y test.

Se generaron mapas de calor de ambas clases para elegir los atributos convenientemente. Para cada clase se calculo el valor promedio de cada pixel.
En la figura \ref{fig:mapas_calor} se observa que
hay una gran diferencia entre las filas 10 y 15 y las columnas 20 y 23. Para la letra O hay atributos con pixel negro mientras que
para la letra L son blancos. 

\begin{figure}[H]
     \centering
     \begin{subfigure}[b]{0.45\textwidth}
         \centering
         \includegraphics[width=\textwidth]{mapaDeCalorO.png}
         \caption{Mapa de calor de la letra O}
     \end{subfigure}
     \quad
     \begin{subfigure}[b]{0.45\textwidth}
         \centering
         \includegraphics[width=\textwidth]{mapaDeCalorL.png}
         \caption{Mapa de calor de la letra L}
     \end{subfigure}
     \caption{Mapas de calor de las letras O y L}
     \label{fig:mapas_calor}
\end{figure}

Primeramente se prueba un modelo KNN con 5 vecinos y 3 atributos dentro del rango mencionado anteriormente. Para
los distintos conjuntos de atributos elegidos, el de los atributos [299, 300, 301] es el que mejor exactitud tiene. Se utilizó este conjunto 
para probar modelos KNN con distintos K (entre 1 y 50). En la figura \ref{fig:exactitud_3atributos}  se observa que
para este conjunto la cantidad de vecinos (K) que mejor exactitud tienen son 13, 34 y 37 con 0.956 de exactitud.
\newline
\newline
Se probaron modelos KNN con 7, 11 y 15 atributos y K = 5. Se observó que con 15 atributos (del rango 293-307) la exactitud es del 0.99.
\newline
Se decidió usar estos atributos para evaluar con distintos K. Se observa en la figura \ref{fig:exactitud_15atributos} que con K = 1 se alcanza la
mayor exactitud (0.995). Es importante tener en cuenta que al usar este valor de K estamos sobreajustando el modelo a los datos de entrenamiento
perdiendo generalización. Es posible que no obtenga la mayor exactitud usando otra semilla para dividir los datos (en train y test)
o si se cambia la proporción de los conjuntos (30\% para test en lugar de 20\%, por ejemplo).

\subsection*{Clasificación Multiclase}
Este experimento busca clasificar imágenes en clases del dataset que representan las letras del alfabeto inglés.
Primeramente se separó el conjunto de datos en desarollo (dev) y validación (held-out). Se separó para el held-out el 20\% de los datos disponibles.
Se observa en la figura \ref{fig:performance} que incrementando la profundidad hasta 11 se consigue una exactitud mayor y a partir de ese punto la
curva comienza a aplanarse, indicando una ganancia en exactitud menor.
\begin{figure}[H] 
    \centering
    \includegraphics[width=0.8\textwidth]{performance_profundidad.png}
    \caption{Performance del Árbol de Decisión según profundidad}
    \label{fig:performance}
\end{figure}
Se realizó un experimento variando los siguientes hiperparámetros del árbol de decisión:
\begin{itemize}
    \item Cantidad máxima de atributos de 1 a 121 con incrementos de 10.
    \item Profundidad máxima del árbol de 1 a 9 con incrementos de 2.
    \item Criterio de impureza Gini o Entropía.
\end{itemize}
Se utilizó la técnica de validación cruzada con K-folding, usando 5 folds. En las figuras \ref{fig:gini} y \ref{fig:entropy} se pueden
observar los resultados del experimento con las variaciones mencionadas.
\begin{figure}[H] 
    \centering
    \includegraphics[width=0.8\textwidth]{gini.png}
    \caption{Exactitud según hiperparámetros}
    \label{fig:gini}
\end{figure}

\begin{figure}[H] 
    \centering
    \includegraphics[width=0.8\textwidth]{entropy.png}
    \caption{Exactitud según hiperparámetros}
    \label{fig:entropy}
\end{figure}
\newpage
De estos experimentos se desprende que el mejor modelo es el siguiente:
\begin{itemize}
    \item Atributos : 121
    \item Profundidad : 9
    \item Criterio de impureza : entropy
    \item Exactitud media : 0.7733
\end{itemize}
Posteriormente, se procedió a entrenar el modelo en todo el conjunto de desarrollo según los hiperparámetros seleccionados. Se realizaron predicciones en el conjunto held-out y se observó la siguiente
performance: \textbf{exactitud = 0.7627}

\begin{figure}[H] 
    \centering
    \includegraphics[width=0.8\textwidth]{matriz.png}
    \caption{Matriz de confusión del modelo elegido}
    \label{fig:matriz}
\end{figure}

Por último, se registraron errores en la matriz de confusión (figura \ref{fig:matriz}), siendo los mayores la clasificación de Y como
T(25), la O como D(21) y la W como N(18).
\newpage
\section*{Conclusión}
Para el modelo KNN entrenado para clasificación binaria se obtuvo que con 15 atributos
(293-307) y K = 1, la exactitud es del 0.995. Para los caracteres
especificados este modelo muestra un muy buen desempeño. Esta exactitud es alcanzable por tratarse de dos caracteres muy distintos entre si, y posiblemente
no pueda ser replicado con cualquier par de caracteres.
\newline
\newline
\indent Para el problema de Clasificación Multiclase, un árbol de decisión entrenado con los siguientes hiperparámetros:
\begin{itemize}
    \item Atributos : 121
    \item Profundidad : 9
    \item Criterio de impureza : entropy
    \item Exactitud : 0.7627
\end{itemize}
Al evaluar en el conjunto held-out la exactitud obtenida(0.7627) se aproximó a la exactitud media obtenida al seleccionar el mejor modelo de los 
experimentos(0.7733).
\newline
Se verifica la utilidad de la matriz de confusión para registrar los errores del modelo al clasificar caracteres
parecidos entre sí.
